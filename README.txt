Portfolio site, Heorhii Andruskyi

Files:
- index.html: the whole site. Project texts are in the block that starts with "const P=[" near the top of the script. To add or change a project, edit that block.
- img/: all images and the coin video. Keep the file names, or change them in the "const IMG=" line.
- Heorhii_Andruskyi_CV_EN_NL.pdf: the CV that the Contact section links to.

To publish: upload this whole folder (not a zip inside a folder) to a static host, for example Netlify Drop or GitHub Pages.
To update later: change the files and upload the folder again.
